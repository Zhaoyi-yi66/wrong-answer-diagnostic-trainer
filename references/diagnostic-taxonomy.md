# Diagnostic Taxonomy

Use the narrowest category supported by the learner's visible work. A diagnosis is an evidence-backed hypothesis, not a label.

## Core categories

| Category | Observable signals | Useful contrast check | Targeted response |
|---|---|---|---|
| Number fact retrieval | Correct method, isolated basic-fact error; inconsistent across repetitions | Same fact in reversed order and inside a larger calculation | Short retrieval set with immediate checking |
| Place value | Misaligned digits; treats tens/ones as interchangeable; zero placeholder lost | Same digits in a different place-value arrangement | Place-value chart or decomposition |
| Carrying or borrowing | First divergence occurs at regrouping; non-regrouping items are correct | Matched pair with and without regrouping | Concrete decomposition, then faded scaffold |
| Operation selection | Calculation is internally correct but the chosen operation does not match the relationship | Two similar wordings requiring different operations | Contrast problems and verbal justification |
| Procedure or sequence | Skips, swaps, or repeats a required step | Same concept with one step removed or reordered | One worked example, completion problem, independent problem |
| Symbol interpretation | Misreads `>`, `<`, `=`, parentheses, decimal point, fraction bar, or operation sign | Same values with a different symbol | Explicit symbol meaning plus minimal pairs |
| Order of operations | Calculates strictly left-to-right when priority applies | Matched expressions with and without parentheses | Mark operation groups before calculating |
| Fraction meaning | Treats numerator and denominator independently or adds denominators incorrectly | Visual model and equal-denominator contrast | Area/number-line representation before algorithm |
| Unit or conversion | Number work is correct but units are omitted, mixed, or converted in the wrong direction | Same values expressed in one unit vs two units | Unit relationship table and dimensional check |
| Reading or modelling | Misses a condition, reverses the relationship, or cannot translate language into an expression | Shortened wording with the same mathematical structure | Highlight quantities, relationship sentence, then equation |
| Transcription | Copies a number or sign incorrectly before otherwise valid work | Ask learner to read back and recopy without solving | Deliberate copy-check routine |
| Execution slip | Method and representation are sound; a single inconsistent step appears | Immediate parallel item; repeated success lowers concern | Checking routine, not full reteaching |

## Confidence rules

- **High:** The same first divergence appears in at least two comparable items, or the learner explicitly explains the incorrect rule.
- **Medium:** One item strongly indicates a category and a contrast item partially supports it.
- **Low:** Only one answer is available, working is absent, or multiple causes fit equally well.

Never convert low-confidence evidence into a stable learner trait. Use a contrast question to discriminate between the leading explanations.

## First-divergence method

1. Reconstruct a valid solution path.
2. Align the learner's steps with that path.
3. Mark the earliest non-equivalent transformation or incorrect fact.
4. Separate the primary cause from downstream consequences.
5. Check whether an alternative valid method could explain the learner's work.

## Language rules

Prefer:

- "在十位退1后，个位没有增加10。"
- "计算步骤正确，但题意要求比较相差多少，应使用减法。"
- "目前只有一道题，暂时判断为可能的符号识别问题。"

Avoid:

- "孩子太粗心。"
- "基础很差。"
- "完全不会。"
- Claims about attention disorders, intelligence, motivation, or learning disabilities.
